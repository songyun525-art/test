# 윤송이의 내집찾기

같은 돈으로 살 수 있는 가장 좋은 아파트를 찾도록 돕는 비교 서비스. 경기도부터 시작한다.

- 아파트 2~3곳(단지명, 평형)을 넣으면 입지·세대수·연식·1/3/5/10년 상승률·호재로 종합점수를 낸다.
- 기준가 ±5% 안에 드는 다른 단지를 평형과 상관없이 추천한다 (예: 59㎡ 검색 시 다른 단지 84㎡도 추천).

## 1단계: 데이터 수집 (`collector/`)

필요한 것

| 환경변수 | 발급처 | 쓰는 곳 |
|---|---|---|
| `DATA_GO_KR_KEY` | [공공데이터포털](https://www.data.go.kr) 일반 인증키(Decoding). 아래 API를 각각 활용신청 | 실거래가, 단지정보 |
| `KAKAO_REST_KEY` | [카카오 개발자](https://developers.kakao.com) REST API 키 | 2단계 입지 계산 |

활용신청할 API
- 국토교통부_아파트 매매 실거래가 자료 (상세 자료가 아닌 기본 자료. 기본 자료에도 필요한 항목이 다 있다)
- 국토교통부_공동주택 단지 목록제공 서비스
- 국토교통부_공동주택 기본 정보제공 서비스

실행

```bash
pip install -r requirements.txt
python -m collector.fetch_trades --check      # 시군구 코드가 맞는지 지난달 거래 건수로 확인
python -m collector.fetch_trades --years 10   # 경기도 10년치 실거래 (약 5,500회 호출)
python -m collector.fetch_complexes           # 단지 목록 + 단지별 기본·상세정보
python -m collector.build_db                  # data/naezip.sqlite 생성, 매칭률 출력
```

- 모든 수집 스크립트는 이미 받은 파일을 건너뛴다. 하루 호출 한도(개발계정 1만 회)에 걸리면 다음 날 다시 실행하면 이어서 받는다.
- `fetch_trades`는 최근 3개월을 매번 다시 받는다 (실거래 신고는 계약 후 30일 안에 하므로 늦게 들어오는 건이 있다).

### 데이터 규칙

- **평형 버킷**: 전용 49~66㎡ → 59, 66~76 → 74, 76~90 → 84, 그 밖은 소형/대형.
- **기준가**: 단지×평형의 최근 3개월 실거래 중위가. 거래가 없으면 6개월, 12개월로 넓힌다. 호가 공개 API가 없어서 실거래로 대신한다.
- **상승률**: 현재 3개월 창과 N년 전 3개월 창의 ㎡당 중위가 비교. 표본 수는 `n1`~`n10`에 `과거/현재` 건수로 남긴다.
- 해제된 거래와 직거래는 시세 계산에서 뺀다.
- 실거래(aptSeq)와 K-apt 단지(kaptCode)는 같은 읍면동 안에서 단지명 → 지번 → 이름 포함 순으로 매칭한다.
